## Reporting a Vulnerability

Security is a fundamental priority for **HybridCache.Plus**, especially given its role in handling multi-tenant isolation, data caching, and distributed cross-pod invalidations.

If you discover a security vulnerability, please **do NOT open a public GitHub issue**.

Instead, report it through one of the following channels:

1. **GitHub Private Vulnerability Reporting**:
   Go to the [Security Advisories tab](https://github.com/sagasta/HybridCachePlus/security/advisories/new) and submit a private draft.
2. **Email**:
   Contact the repository maintainer privately via GitHub profile contact details.

### What to Include
- A clear description of the vulnerability.
- Minimal reproduction steps, sample code, or proof of concept.
- Affected packages and versions.
- Potential impact on caching layers, data isolation, or denial of service.

### Response Commitment
- We will acknowledge receipt of your report within **48 hours**.
- We will provide updates on the investigation and release a fix as promptly as possible before public disclosure.
